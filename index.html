🏆 2026世界盃最新賽制

2026年世界盃由美國、加拿大、墨西哥三國聯合主辦，參賽隊伍從32隊擴充至48隊，是史上規模最大的世界盃。

⚡ 核心變化：48隊 → 12組 × 4隊 → 小組前2名 + 8隊最佳第三 → 32強淘汰賽

📐 越位規則 — 互動示意圖

🖱 拖動下方球場中的球員與皮球，系統會即時判斷是否越位！

支援滑鼠拖拽（桌面端）及觸控拖拽（手機/平板）｜拖動紅色進攻球員、藍色防守球員、或黑色皮球

✅ 不越位 — 合法進攻
進攻球員 防守球員 皮球 越位線

拖動圓點改變位置，即時判斷越位

越位三條件（全部滿足）：
① 在對方半場
② 比倒數第二名防守球員更近底線
③ 比皮球更近底線

📖 越位規則補充說明

  • 門將計算在內：門將是防守球員之一，通常是最後一名；越位線由倒數第二名防守球員決定
  • 界外球無越位：擲界外球時，接球隊友即使處於越位位置也不算犯規
  • 後場回傳無越位：球員在自己半場接球，不存在越位
  • 角球無越位：角球直接傳球不構成越位
  • 球門球無越位：球門球開出時不計算越位
  • 「參與進攻」才算：僅處於越位位置但不參與進攻/不影響比賽，裁判可不吹罰
  • VAR覆核：所有入球都會經VAR檢查越位，精準至毫米級

📋 足球規則全面解析

以下涵蓋世界盃賽事中最關鍵的規則，幫助你從零基礎進階為專業觀眾。

🟨 黃牌與紅牌

  • 黃牌（警告）：犯規、拖延時間、不君子行為、未獲准入場、重複犯規
  • 兩黃變一紅：同一場累積2張黃牌 = 紅牌離場
  • 直接紅牌：嚴重犯規、暴力行為、蓄意手球阻止入球、辱罵裁判
  • 紅牌 = 即時離場，球隊少打一人，且下場停賽
  • 淘汰賽黃牌在準決賽前清零（確保決賽可上陣）

🎯 十二碼（點球）

  • 防守方在禁區內犯規或手球 → 判十二碼
  • 球放於12碼點（距球門11米）
  • 只有門將和主射球員可進入禁區
  • 門將須站在白線之上，射門前不可向前移動
  • 十二碼大戰：5輪制，平手則進入突然死亡

📡 VAR（影像輔助裁判）

  • 4類可覆核：入球/越位、十二碼判決、直接紅牌、錯誤身份
  • VAR團隊在影像控制室遠程協助主裁判
  • 主裁判可選擇場邊屏幕親自觀看重播
  • 2026世界盃將使用半自動越位系統（AI+骨骼追蹤）
  • 球迷可通過轉播看到VAR覆核過程

⏱ 補時與加時

  • 傷停補時：每半場結束前，補償受傷/換人/VAR等延誤
  • 2022世界盃起採用超長補時（補時可達8-15分鐘）
  • 加時賽：淘汰賽和波後30分鐘（上下半場各15分鐘）
  • 加時賽不設「黃金入球」（即不採用突然死亡法）
  • 加時賽每隊可多換1人（共6個換人名額）

🔄 換人規則（2026更新）

  • 每場最多5個換人名額（3次換人時機 + 中場休息）
  • 加時賽額外+1個換人名額及額外1次換人時機
  • 腦震盪替補：若球員疑似腦震盪，可使用額外替補名額
  • 被換走的球員不可再次上陣

🎯 提升觀賽眼光的實戰方法

  1. 固定追2-3隊：熟記正選陣容、常用陣型、核心球員位置與習慣
  2. 賽後睇數據：控球率、射正次數、傳球成功率、xG（預期入球值）、跑動距離
  3. 觀察換人邏輯：落後時換前鋒/翼鋒加強攻勢；領先時換後腰/中堅鞏固防守
  4. 留意無球跑動：不只是看持球者，更要看隊友如何拉空位、牽制後衛
  5. 分析防守結構：觀察防守線的高度、越位陷阱的執行、中場逼搶的協調
  6. 觀看重播與分析節目：賽後專家分析能幫助理解戰術細節
  7. 使用戰術App：如SofaScore、FotMob等提供即時熱力圖與球員評分
